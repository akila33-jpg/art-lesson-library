# 阿錡拉老師的美術教案庫

網址：https://akila33-jpg.github.io/art-lesson-library/

Akila 阿錡拉老師的特教美術教案，給身心障礙朋友、長輩與孩子。每份教案都有：

- **教案頁**：目標、媒材、步驟、調整方式、步驟圖、成果照片、參考來源、完整教案內容
- **上課簡報**：老師做過的 PowerPoint／教學簡報，已轉成網頁可翻頁的畫面，上課按「上課簡報」就能投影（方向鍵、簡報筆、點畫面左右側或手機滑動都可以；F 全螢幕、Esc 離開）
- **步驟簡報**：還沒有投影片檔的教案，會依步驟自動做成大字簡報，用法相同
- **列印／存成 PDF**：教案頁上方的按鈕

網站是純 HTML／CSS／JavaScript，不需要編譯；推到 `main` 之後 GitHub Pages 約 1 分鐘自動更新。打開過一次後，沒有網路也能使用。

## 資料夾

```
index.html            網頁外框
assets/site.css       樣式
assets/app.js         搜尋、篩選、教案頁、上課簡報與步驟簡報
assets/decks/<編號>/  該教案的上課簡報（每頁一張圖，另有 PDF）
data/lessons.json     所有教案（網站只讀這一個檔）
data/_template.json   新增教案時複製用的範本
images/<教案編號>/     該教案的步驟圖與成果照片
sw.js                 離線快取（改版後把 VERSION 加 1）
```

## 新增一份教案

1. 打開 `data/_template.json`，複製整段 `{ … }`。
2. 打開 `data/lessons.json`，貼在最後一份教案的 `}` 後面（記得中間加一個逗號 `,`）。
3. 改掉內容。欄位說明：

| 欄位 | 說明 |
| --- | --- |
| `id` | 教案編號，跟 Google Drive「00_共用教案庫」一致，例如 `L018` |
| `title`、`subtitle`、`summary` | 名稱、副標、兩三句簡介（首頁卡片會顯示） |
| `unit` | 單位類型，**請寫一般說法**，例如「特教學校」「長輩據點」「兒童美術班」，不寫機構全名 |
| `ages` | 適用年齡：`幼兒`、`兒童`、`青少年`、`成人`、`長輩`（可多選） |
| `students` | 學生類別／障別，例如 `心智障礙`、`自閉症`、`多重障礙`、`長輩`、`一般` |
| `themes`、`media`、`season`、`tags` | 主題、媒材、節令（如 `新年`、`聖誕節`、`不限`）、標籤；篩選按鈕會自動出現 |
| `duration` | 分鐘數（數字；不確定就寫 `0`），`durationText` 是顯示用文字 |
| `goals`、`materials`、`adapt` | 目標、媒材清單、調整方式（每一項一行字） |
| `steps` | 步驟。`t` 是時間或小標，`d` 是內容；加上 `"head": true` 會變成分段標題。**簡報模式就是用這裡產生的** |
| `sections` | 其他段落（講稿、紀錄表…），`rows` 裡一格一行字，兩格以上會變成表格 |
| `refs` | 參考來源連結 |
| `diagram`、`cover` | 步驟圖、卡片封面圖的路徑（可留空，會自動用顏色做封面） |
| `color` | 這份教案的主色，例如 `#1f5460` |
| `featured` | `true` 會出現在首頁「精選課程」 |
| `date` | 建檔年月，例如 `2026-12`（課程紀錄頁依此排列） |

4. 存檔、推上 GitHub。可以用 <https://jsonlint.com/> 檢查格式有沒有打錯。


## 加入上課簡報

老師若為某一堂課做了 PowerPoint、Google 簡報或 HTML 簡報，請放到網站上，不要只留雲端連結（未公開分享的雲端檔，上課時別人打不開）。

1. 把簡報匯出成 PDF（Google 簡報：檔案 → 下載 → PDF）。
2. 用工具把每一頁存成圖片，放到 `assets/decks/<教案編號>/`，檔名用 `01.jpg`、`02.jpg`……建議寬約 1600 px。也可以再放一份 `deck.pdf` 供下載。
3. 在該教案的 `deck` 欄位填上：
   ```json
   "deck": {
     "title": "上課簡報",
     "pages": 12,
     "slides": [
       "assets/decks/L018/01.jpg",
       "assets/decks/L018/02.jpg"
     ],
     "pdf": "assets/decks/L018/deck.pdf",
     "note": "（可寫簡短說明，沒有就留空）",
     "originals": [
       {
         "label": "Google 簡報原檔",
         "url": "https://docs.google.com/presentation/d/……/edit",
         "sharing": "private"
       }
     ]
   }
   ```
   `sharing` 寫 `private`（僅老師自己開得開）或 `anyoneWithLink`（公開連結）。不要在網站上改雲端分享設定，除非老師自己同意。
4. 上架前請檢查每一頁：
   - 看不到學員的臉、名字、制服或可辨識資訊
   - 不寫老師的電話與地址；機構名稱請用一般說法
   - 公有領域的名作圖片可以放；仍受著作權保護的作品不要嵌入，改放館方連結
   - 避免使用本站不用的醫療相關說法
5. 若某一頁有人像或不宜公開的內容，請拿掉該頁再上架，並在 `note` 裡說明拿掉了哪一類畫面。
6. 沒有現成投影片的教案，不必勉強製作；網站的「步驟簡報」會自動把每個步驟做成大字頁面。

## 加入成果照片

1. 把照片放進 `images/<教案編號>/`，例如 `images/L017/photo-01.jpg`（建議寬 1600 px 以內、JPG）。
2. 在該教案的 `photos` 加一筆：
   ```json
   "photos": [ { "file": "photo-01.jpg", "caption": "羊年螺旋刮畫作品", "alt": "彩虹螺旋刮畫的小羊" } ]
   ```
3. **上架前請確認**：
   - 只拍作品，看不到臉、名字、制服、名牌或機構招牌
   - 已取得機構與家長（或本人）同意
   - 檔名不要用學員名字

## 內容守則

- 不寫學員姓名、照片、可辨識資訊；不寫老師的電話與地址。
- 機構與班級改用一般說法（例如「長輩據點」「特教學校」「兒童美術班」）。
- 這是藝術陪伴與創作課程，不使用醫療相關說法。
- 公有領域或明確開放授權的名作才放圖片；仍受著作權保護的作品只放館方網站連結。
